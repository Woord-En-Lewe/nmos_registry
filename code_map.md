# Code Map for NMOS Registry

## Summary
The NMOS Registry implements the AMWA IS-04 specification for discovery and registration of networked media resources. It follows the Module-Infrastructure-Module (MIM) architecture, separating business logic from technical implementations.

## Architecture
- **Business Module (BM)**: `internal/registry` (future logic for resource management)
- **Infrastructure Module (IM)**: `internal/infrastructure`
  - **Persistence**: `internal/infrastructure/persistence` using SQLite (in-memory) and `sqlc` for type-safe queries. Uses `modernc.org/sqlite` (pure Go driver).
  - **Transport**: `internal/infrastructure/transport/http` using `go-chi/chi` for routing NMOS APIs, and `internal/infrastructure/transport/websocket` for WebSocket connections using `gorilla/websocket`.
  - **mDNS/DNS-SD**: `internal/infrastructure/mdns` using `github.com/grandcat/zeroconf` for service discovery via mDNS announcement and browsing.

## When to Use
Use this project as a centralized NMOS IS-04 Registration and Query service for media networks.

## Public Types
### `internal/registry`
- `Node`, `Device`, `Source`, `Flow`, `Sender`, `Receiver`: Business module representations of IS-04 NMOS resources.
- `Subscription`: Represents a Query API subscription for real-time resource change notifications.
- `IRepository`: Interface for resource persistence (CRUD operations and health monitoring).
- `INotifier`: Interface for real-time updates (Query API notifications).
- `ISubscriptionRepository`: Interface for subscription persistence (CRUD operations).
- `ResourceManager`: Core logic for managing NMOS resource lifecycles (registration, updates, deletion).
- `HeartbeatEngine`: Manages Node health timestamps and background garbage collection for expired resources.
- `SubscriptionEngine`: Manages Query API subscriptions and coordinates real-time notifications via WebSocket.
- `ResourceType`: Enum for NMOS resource categories (node, device, source, flow, sender, receiver).

### `internal/infrastructure/persistence/db` (Generated by sqlc)
- `Nodes`: Represents an IS-04 Node resource in the database.
- `Devices`: Represents an IS-04 Device resource.
- `Sources`: Represents an IS-04 Source resource.
- `Flows`: Represents an IS-04 Flow resource.
- `Senders`: Represents an IS-04 Sender resource.
- `Receivers`: Represents an IS-04 Receiver resource.
- `Subscriptions`: Represents a Query API subscription.
- All resource types use `json.RawMessage` for complex NMOS fields (tags, api, caps, etc.) to ensure type safety and flexibility.

### `internal/infrastructure/mdns`
- `Announcer`: Interface for mDNS service announcement.
- `Browser`: Interface for DNS-SD service discovery browsing.
- `Config`: Configuration for mDNS announcement including hostname, ports, priority, and TTL.
- `Service`: Represents an mDNS service definition with service type, instance name, port, TXT records.
- `DiscoveredService`: Represents a discovered mDNS service result.
- `NewAnnouncer(cfg *Config) (Announcer, error)`: Creates a new mDNS announcer.
- `NewBrowser() (Browser, error)`: Creates a new DNS-SD browser.
- `RegistrationServiceType`: DNS-SD service type constant `_nmos-registration._tcp`.
- `QueryServiceType`: DNS-SD service type constant `_nmos-query._tcp`.

### `internal/infrastructure/transport/websocket`
- `Manager`: WebSocket connection manager that implements `INotifier` for broadcasting resource changes to subscribed clients.

## Public Functions
### `internal/registry`
- `NewResourceManager(repo IRepository) *ResourceManager`: Creates a new instance of the ResourceManager.
- `NewHeartbeatEngine(repo IRepository, expiryDuration time.Duration, cleanupInterval time.Duration) *HeartbeatEngine`: Creates a new HeartbeatEngine.
- `HeartbeatEngine.Heartbeat(ctx context.Context, nodeID string) error`: Updates the health timestamp for a Node.
- `HeartbeatEngine.StartGarbageCollector(ctx context.Context)`: Runs a background loop to prune expired resources.
- `HeartbeatEngine.PerformCleanup(ctx context.Context)`: Manually triggers a cleanup of expired Nodes.
- `NewSubscriptionEngine(repo ISubscriptionRepository) *SubscriptionEngine`: Creates a new SubscriptionEngine.
- `SubscriptionEngine.CreateSubscription(ctx context.Context, resourcePath string, params json.RawMessage, maxUpdateRateMs *int, persist *bool, secureWebsocket *bool) (*Subscription, error)`: Creates a new subscription.
- `SubscriptionEngine.GetSubscription(ctx context.Context, id string) (*Subscription, error)`: Retrieves a subscription by ID.
- `SubscriptionEngine.ListSubscriptions(ctx context.Context) ([]Subscription, error)`: Lists all subscriptions.
- `SubscriptionEngine.DeleteSubscription(ctx context.Context, id string) error`: Deletes a subscription.
- `SubscriptionEngine.Notify(ctx context.Context, resourceType ResourceType, action string, data interface{}) error`: Notifies subscribers of resource changes.

### `internal/infrastructure/persistence`
- `SQLiteRepository`: Implementation of `registry.IRepository` using SQLite and sqlc.
- `NewSQLiteRepository(db *sql.DB) *SQLiteRepository`: Creates a new instance of the SQLiteRepository.
- `InitDB(db *sql.DB) error`: Initializes the database schema using the embedded `schema.sql`.

### `internal/infrastructure/transport/http`
- `NewQueryHandlers(repo registry.IRepository, subscriptionEngine *registry.SubscriptionEngine, wsManager *websocket.Manager, wsBaseURL string) *QueryHandlers`: Creates QueryHandlers with subscription and WebSocket support.

### `internal/infrastructure/transport/websocket`
- `NewManager(subscriptionEng *registry.SubscriptionEngine) *Manager`: Creates a new WebSocket manager.
- `Manager.HandleWebSocket(w http.ResponseWriter, r *http.Request, subscriptionID string)`: Handles WebSocket upgrade and connection.
- `Manager.Run()`: Starts the manager's main loop for handling client connections and broadcasts.
- `Manager.Notify(ctx context.Context, resourceType registry.ResourceType, action string, data interface{}) error`: Broadcasts resource changes to subscribed clients.

### `cmd/server`
- `main()`: Entry point for the NMOS Registry server. Initializes DB, creates all engines and managers, and starts the HTTP server.
